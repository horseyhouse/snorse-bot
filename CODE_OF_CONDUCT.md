# Code of conduct

Be kind, constructive, and respectful. Assume good intent while addressing
impact directly.

Harassment, discrimination, threats, doxxing, sexualized attention, and
publishing another person's private data are not acceptable. Project
maintainers may edit or remove contributions and restrict participation to
protect the community.

Report conduct concerns privately to the repository owner through the contact
method on their GitHub profile. Reports will be handled as confidentially as
practical.
